# Staff Pulse

## Запуск

Требуется Node.js с поддержкой `--env-file-if-exists`. Из корня проекта:

```bash
npm install
npm run dev
```

Команда запускает mock API и Vite client. Dashboard доступен по адресу,
который выведет Vite (обычно `http://localhost:5173/`). API предоставляет
`GET /api/org-tree`; запросы к нему в development проходят через Vite proxy.
Порт API можно изменить через `API_PORT` в `.env`.

## Предсказуемые realtime-обновления

Обычный режим (`REALTIME_MODE=generated`) генерирует детерминированные, но
распределённые по fixture обновления. Чтобы наблюдать пересчёт агрегатов у
одного отдела и его дивизиона, добавьте в `.env`:

```env
REALTIME_MODE=scripted
REALTIME_INTERVAL_MS=5000
```

После перезапуска `npm run dev` сервер циклически отправляет шесть patch-событий,
описанных комментариями в `server/realtime-generator.mjs`: меняются performance
команды 1.1.1, headcount команды 1.1.2 и budget команды 1.1.3, затем те же
значения возвращаются к исходным. Это наглядно меняет агрегированные показатели
`Отдела 1.1` и `Дивизиона 1` в таблице и detail-панели canvas.

## AI в разработке

Проект создавался с использованием AI-assisted engineering. В рамках текущей
задачи Codex сгенерировал и существенно изменил Foundation-документацию и
обновил OpenSpec-отметку после проверки реализации. Ранее созданные исходники
и коммиты присутствуют в checkout до текущей задачи; их авторство и возможные
ручные переписывания по доступным данным достоверно не разделяются. Поэтому
ручные изменения в этой секции не приписываются конкретному автору без
дополнительной истории.
